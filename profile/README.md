## `> WHOAMI`

Somos una comunidad en español dedicada a aprender, practicar y compartir conocimientos sobre **ciberseguridad, hacking ético y desarrollo de software**.

En esta organización publicamos proyectos creados por la comunidad: herramientas, bots, laboratorios, recursos educativos y experimentos desarrollados para aprender juntos.

## `> NUESTROS PROYECTOS`

- 🛡️ Herramientas de ciberseguridad
- 🤖 Bots y automatizaciones
- 🚩 Laboratorios y retos CTF
- 💻 Proyectos de programación
- 📚 Recursos educativos en español
- 🔍 OSINT, análisis y pentesting

## `> COLABORA`

¿Quieres participar en alguno de nuestros proyectos?

1. Explora nuestros repositorios.
2. Revisa el `README.md` y las tareas disponibles.
3. Crea un fork y prepara tu contribución.
4. Envía un Pull Request explicando tus cambios.

Todas las contribuciones deben tener fines **educativos, éticos y legales**.
